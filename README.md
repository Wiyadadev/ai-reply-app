# AI Chat Web App

This is a simple AI chatbot web application built with Flask and OpenAI API.

## Features
- Chat with AI
- Simple and clean UI
- Fast response

## Tech Stack
- Python (Flask)
- OpenAI API
- HTML/CSS

## How to run
1. Install:
   pip install -r requirements.txt

2. Run:
   python app.py
